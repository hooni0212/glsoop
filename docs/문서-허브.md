## 1. 문서 목적

- 서버 구현/런타임과 직접 연결된 문서는 이 저장소를 기준으로 유지한다.
- 공통 운영 / 출시 / 심사 / archive 문서는 `../glsoop-ops/docs/index.md`를 canonical로 사용한다.
- 공통 운영 문서 canonical: `../glsoop-ops/docs/operations/glsoop/`
