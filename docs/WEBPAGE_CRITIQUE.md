# 웹페이지 개선 제안 (최근 코드 기준)

## 관찰 사항과 개선 방향

1. **계절/폰트 자원 과다 로드**
   홈은 손글씨·명조 폰트 2종과 겨울 테마 CSS를 즉시 불러오고, 관리자 화면은 폰트 3종과 네 계절 테마 CSS를 모두 로드하고 있어 초기 페이로드가 커집니다.【F:public/index.html†L37-L62】【F:public/html/admin.html†L14-L42】
   → 사용 중인 계절만 지연 로드하거나 한 번에 하나의 테마 파일만 교체하는 식으로 전환하고, 폰트는 본문/포인트용 1~2종만 선별 로딩하세요.

2. **피드 로딩/빈 상태 피드백 한계**
   메인 피드는 네트워크가 느릴 때 단순 문구만 보여주기 때문에 진행 상황을 체감하기 어렵습니다. 첫 로드 실패 시에도 텍스트만 표시됩니다.【F:public/js/index.js†L224-L318】
   → 스켈레톤 카드나 인디케이터, 재시도 버튼을 추가해 로딩/빈 상태를 시각적으로 안내하면 체감 품질이 올라갑니다.

3. **테마 선택 적용 범위 제한**
   관리자 페이지에서 로컬 스토리지 기반 계절 토글이 생겼지만 `body` 클래스만 전환하므로 메인/포스트 화면에는 선택 테마가 반영되지 않습니다. 홈에서는 여전히 겨울 테마 CSS를 고정 로드합니다.【F:public/js/admin.js†L85-L124】【F:public/index.html†L56-L64】
   → 로컬 스토리지에 저장한 테마를 공통 진입점에서 읽어 `#seasonTheme`의 href를 교체하거나, 서버에서 현재 테마 값을 내려 전체 페이지가 일관되게 테마를 공유하도록 확장하세요.
