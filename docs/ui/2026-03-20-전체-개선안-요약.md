## 1. 핵심 결정

- `post3`, `editor3`는 당장 메인 전환 대상이 아니라 추후 업데이트 과제로 보류한다.
- 현재 우선순위는 `기존 post / editor`의 사용성 문제와 렌더 일관성 문제를 먼저 정리하는 것이다.

## 2. 기존 Editor / Post 관련 개선 포인트

### 2.1 레이아웃 편집기와 실제 렌더 위치 불일치

![기존 editor 레이아웃 편집기와 실제 렌더 위치 불일치](./assets/2026-03-20-overall-review/01-image.png)

- 레이아웃 편집 모드에서 보이는 제목/본문 박스 위치와 실제 결과물 위치가 맞지 않는 문제가 있다.
- 제목뿐 아니라 본문도 같은 문제가 있는 것으로 보인다.
- 개선 방향은 “정규화된 박스 좌표”보다 `일반 디자인 툴처럼 텍스트 박스 크기와 위치를 직접 보면서 이동`하는 쪽에 가깝다.

정리:

- 편집 캔버스의 박스와 실제 렌더 결과가 1:1로 맞아야 한다.
- 제목/본문 박스는 텍스트 크기에 맞춘 실제 박스처럼 움직여야 한다.
- 편집기에서 본 좌표와 저장 후 결과가 달라지면 안 된다.

### 2.2 카드 내부 제목과 외부 제목의 중복 노출

![카드 내부 제목 배치 후 외부 제목 노출이 함께 보이는 예시](./assets/2026-03-20-overall-review/02-image-1.png)

- 제목을 카드 이미지 안에 배치한 경우, 카드 바깥의 별도 제목 영역이 다시 보일 필요가 없다.
- 개선 방향은 `카드 내부 제목 사용 시 상단 제목 노출 제거`다.

정리:

- 제목 노출 규칙을 하나로 통일해야 한다.
- 카드 내부 제목을 사용하는 레이아웃에서는 상단 제목 영역을 숨기는 조건이 필요하다.

### 2.3 저장 후 마이페이지에서 제목이 두 번 보이는 문제

![마이페이지에서 제목이 중복으로 보이는 예시](./assets/2026-03-20-overall-review/03-image-2.png)

- 편집 후 저장했을 때 `마이페이지`에서 제목이 두 개처럼 보이는 문제가 확인되었다.
- 작성 메모상 이 문제는 마이페이지에서만 재현되는 것으로 보인다.
- 개선 방향은 카드 렌더링 경로를 하나로 통일하는 것이다.

정리:

- 마이페이지 전용 카드 렌더 예외를 줄이고, post 카드 렌더를 SSOT로 정리할 필요가 있다.
- “카드 내부 텍스트 + 외부 메타 제목”이 동시에 남는 조건을 점검해야 한다.

## 3. MyPage 관련 개선 포인트

### 3.1 수정 / 삭제 버튼 위치 조정

![마이페이지 카드 액션 위치 검토 예시](./assets/2026-03-20-overall-review/03-image-2.png)

- 마이페이지 내부 카드 액션 위치가 어색해 보여 재배치가 필요하다.

정리:

- 수정 / 삭제는 카드 감상 영역을 침범하지 않는 위치로 이동해야 한다.
- 액션 버튼은 메타 영역 또는 카드 하단 제어 영역으로 정리하는 편이 적절하다.

### 3.2 북마크 기능 웹-모바일 동기화

- 웹 북마크 UX를 `glsoop-mobile` 기준과 맞추자는 요구가 있다.
- 구체적으로는 여러 개 북마크 처리와 공감 표시 sync 형태를 웹에도 맞추는 것이 목표다.

정리:

- 북마크 정보 구조와 UI 상태 표현을 모바일과 비교해 맞춰야 한다.
- 웹/모바일 간 좋아요/북마크 반영 타이밍과 표기 방식의 차이를 점검해야 한다.

## 4. 업적 페이지 관련 개선 포인트

### 4.1 “오늘의 기록” 줄바꿈 어색함

![업적 페이지 상단 요약 화면](./assets/2026-03-20-overall-review/04-스크린샷-2026-03-20-10.19.49.png)

- 업적 페이지 내 `오늘의 기록` 섹션에서 텍스트 줄바꿈이 어색하다는 지적이 있다.

정리:

- 카드 너비 대비 텍스트 폭, line-height, word-break 기준을 다시 점검해야 한다.

### 4.2 숲 지도 영역 삭제 제안

![숲 지도와 업적 상세가 함께 보이는 현재 구조](./assets/2026-03-20-overall-review/05-image-3.png)

![업적 목록 중심으로 단순화가 필요한 현재 구조](./assets/2026-03-20-overall-review/06-image-4.png)

- 상단의 숲 지도형 비주얼이 아래 업적 목록과 의미상 겹친다.
- 결과적으로 정보 중복과 화면 혼잡을 만든다고 판단되며, 삭제 제안이 포함되어 있다.

정리:

- 업적 페이지는 상징 비주얼보다 업적 목록 자체를 중심으로 단순화하는 방향이 적절하다.
- “숲 지도” 영역은 제거 후보로 본다.
