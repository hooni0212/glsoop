# 프롬프트 글쓰기 퀘스트 진행 현황

작성일: 2026-05-04

## 범위

- Instagram 게시글 주제를 글숲 퀘스트로 연결하는 서버 기반을 추가한다.
- 관리자가 프롬프트형 퀘스트와 시즌 캠페인 보상을 만들고 삭제할 수 있게 한다.
- 캠페인 보상으로 시즌 배지를 지급하는 초안을 포함한다.

## 완료된 작업

- `PROMPT_POST_CREATED` 조건 타입을 추가했다.
- 글 작성 API가 `quest_context`를 받아 프롬프트 퀘스트 진행도를 갱신한다.
- `quest_post_submissions` 테이블을 추가해 프롬프트 퀘스트별 제출 글을 추적한다.
- 프롬프트 퀘스트 `ui_json` 검증을 관리자 API에 추가했다.
- 퀘스트 템플릿/캠페인 삭제 시 사용자 진행 상태와 프롬프트 제출 기록을 함께 정리한다.
- 관리자 페이지에 퀘스트 운영 흐름 요약, 캠페인 연결 상태, 보상 코스메틱 요약을 추가했다.
- 시즌 캠페인 보상용 배지 초안으로 여름/가을 배지를 추가하고 봄/겨울 배지 메타를 정리했다.
- 성장 페이지의 데스크탑 퀘스트 레이아웃을 긴 제목과 카드 메타가 겹치지 않도록 조정했다.
- E2E에 프롬프트 퀘스트 생성/완료/삭제 흐름과 캠페인 보상 배지 지급 검증을 추가했다.

## 남은 판단

- 프로필 꾸미기 모델은 아직 `badge`/`sticker`까지만 지원한다.
- 업적별 배지 종류는 기본/시즌 배지 수준이라, 업적 코드별 보상 매핑이 필요하다.
- 특별 배경 보상은 현재 DB 체크 제약과 프로필 저장 모델 때문에 별도 확장이 필요하다.
- 원격 서버 적용 시 마이그레이션 실행 여부와 기본 코스메틱 보유 데이터가 함께 확인되어야 한다.

## 검증 상태

- 브랜치 정리 전에 변경 JS 파일 문법 검사와 성장/수익화 관련 E2E를 재실행한다.
- 병합 후 새 브랜치에서 프로필 배경, 업적별 배지, 모바일 업적 페이지 개편 문서를 이어 작성한다.
