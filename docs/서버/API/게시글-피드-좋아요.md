# 게시글 / 피드 / 좋아요 API

기준 라우트: `routes/postRoutes.js`

Base: `/api`

---

## 엔드포인트

작성/수정/삭제:

- `POST /posts` (auth)
- `PUT /posts/:id` (auth)
- `DELETE /posts/:id` (auth)

내 글/좋아요:

- `GET /posts/my` (auth)
- `GET /posts/liked` (auth)

피드/목록:

- `GET /posts/feed` (public)
- `GET /posts` (public)

상세/관련/편집:

- `GET /posts/:id` (public)
- `GET /posts/:id/edit` (auth)
- `GET /posts/:id/related` (public)

좋아요:

- `POST /posts/:id/toggle-like` (auth)

---

## 쿼리/정렬 요약

`GET /posts`/`GET /posts/feed`는 공통 핸들러를 사용하며 아래를 지원합니다.

- 카테고리/태그 필터
- 정렬/페이징
- 뷰어 로그인 여부에 따른 `user_liked` 계산

---

## 데이터 모델 연결

- `posts`
- `likes`
- `hashtags`
- `post_hashtags`
