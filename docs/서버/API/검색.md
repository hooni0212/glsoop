# 검색 API

기준 라우트: `routes/searchRoutes.js`

Base: `/api`

---

## 엔드포인트

- `GET /search` (public)

---

## 쿼리

- `q`: 필수, 1~80자
- `type`: `all | posts | authors` (default `all`)
- `limit`: 1~30 (default 10)
- `offset`: 0 이상 (default 0)

---

## 응답 요약

- `query`
- `type`
- `posts[]`
- `authors[]`
- `meta`
  - `posts_count`
  - `authors_count`
  - `limit`
  - `offset`

---

## 에러 코드

- `400 INVALID_REQUEST`
- `500 INTERNAL_ERROR`
