# 수익화 API

기준 라우트:

- `routes/monetizationRoutes.js`
- `routes/monetizationWebhookRoutes.js`
- `routes/adminRoutes.js` (운영 복구 API)

Base: `/api`

---

## 공개/비공개 API

- `GET /store/catalog` (public)
- `GET /entitlements/me` (auth)
- `POST /purchases/verify` (auth)
- `POST /monetization/webhooks/apple` (provider webhook)
- `POST /monetization/webhooks/google` (provider webhook)

---

## 검증 모드 (`MONETIZATION_VERIFY_MODE`)

- `pending_only` (default)
- `auto_active`
- `receipt_inspect`
- `live_verify`

Strict/Fallback:

- `MONETIZATION_VERIFY_LIVE_STRICT`
- `MONETIZATION_VERIFY_LIVE_FALLBACK_MODE`

---

## 핵심 응답 필드

`POST /purchases/verify`:

- `purchase`
  - `platform`
  - `store_sku`
  - `status`
  - `purchased_at`
  - `expires_at`
- `entitlements[]`
  - `entitlement_key`
  - `status`
  - `starts_at`
  - `ends_at`
  - `source`

---

## 웹훅 처리 요약

1. 이벤트 원장 기록(`monetization_webhook_events`)
2. purchase 매칭
3. purchase 상태 반영
4. entitlement 동기화
5. 실패/무시 건은 `monetization_alerts` 생성 가능
