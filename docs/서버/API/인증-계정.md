# 인증 / 계정 API

기준 라우트: `routes/authRoutes.js`

Base: `/api`

---

## 엔드포인트

- `POST /signup` (public)
- `POST /verify-email` (public)
- `POST /verify-email/resend` (public)
- `POST /password-reset-request` (public)
- `POST /password-reset` (public)
- `POST /login` (public)
- `POST /logout` (public)
- `GET /me` (auth)
- `GET /me/followings` (auth)
- `PUT /me` (auth)

---

## 핵심 동작

- 회원가입은 `pending_signups` 기반 OTP 인증 완료 후 사용자 생성
- 비밀번호 재설정은 토큰 + 만료시간 검증
- 로그인 시 JWT를 쿠키로 발급
- `GET /me`는 프로필 + 관계 수치(팔로워/팔로잉 등) 포함

---

## OTP 인증 정책 요약

- OTP는 6자리 숫자이며 서버에는 해시(`code_hash`)만 저장
- OTP 유효시간: 10분 (`OTP_TTL_MINUTES = 10`)
- 재발송 쿨다운: 60초 (`OTP_COOLDOWN_MS = 60s`)
- 최대 검증 시도: 5회 (`MAX_OTP_ATTEMPTS = 5`)
- 데이터 보관:
  - 가입 대기: `pending_signups`
  - OTP 상태: `pending_otp_verifications`
- `POST /verify-email/resend`는 레이트리밋(`otpResendLimiter`) 적용
