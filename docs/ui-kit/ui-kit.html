테마

버튼 시안 A/B

글숲은 “동글동글 귀여움”보다 “각이 잡혀있되 끝이 매끄러운” 톤이 맞는 편이라, 기본 라운드는 10~12px을 기준으로 잡았습니다.

시안 A: Glass Primary (추천)
유리 질감에 살짝 힘이 있는 타입. CTA/주요 행동(저장, 확인, 적용) 같은 “1순위 버튼”에 적합.
포인트: 은은한 인셋 하이라이트 + 살짝 올라오는 호버.
시안 B: Glass Outline / Ghost
덜 튀는 타입. 보조 행동(더 보기, 필터, 서브 메뉴)이나 “둘째 버튼”에 적합.
포인트: 배경은 거의 안 깔고, 테두리와 타이포로 정리.

글 분류 / 해시태그 칩

지금 화면에서 “시/에세이/짧은 구절”과 “#해시태그”가 입력 UI처럼 보여서 레이어가 늘어나 보이는 문제가 있습니다. 칩은 ‘정보 라벨’로 느껴지게 정리하는 게 목표.

카테고리 칩 (시안)
시 에세이/일기 짧은 구절
카테고리는 “필터/정체성” 역할이라, 해시태그보다 약간 더 무게감이 있어도 괜찮습니다.
해시태그 칩 (시안)
#개발일지 #겨울 #감성 #산책 #밤공기
해시태그는 ‘딱딱한 버튼’이 아니라 ‘가벼운 라벨’ 톤이 어울립니다.
